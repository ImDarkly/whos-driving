# Who's Driving? / Parking Game

Online multiplayer parking friendslop for Game Off 2026, theme SHIFT. Friends share one car and try to park it. Multiplayer takes priority over optimizing solo play for jam ratings.

Goal from the project brief: a playable itch.io submission by December 1, 2026. First online playtest target: November 5 evening; evaluate the experiment afterward, then stabilize the approved loop and add only playtest-justified polish/challenges.

Fresh Godot + EOSG project. Chum's lobby philosophy and documented Dev Auth testing approach are references only: no fork, imported game code, or dependency on its repository. This user decision supersedes all older Chum reuse/adaptation wording in the source pages.

The current design experiment and its approval status are described in SPEC.md. The existing playable predates that design revision; implementation evidence is in KNOWLEDGE.md. Other ideas (damage, scoring, gearbox roles, role rotation, variants, replays, etc.) are uncommitted; consult the source rather than copying the backlog here.
